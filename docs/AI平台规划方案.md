# AI 创作平台规划方案（精简版）

> 两个模型：GPT-image-2（生图）+ Seedance 2（生视频）
> 两类用户：学员（批量导入+手动赠积分）、普通用户（注册+自助买套餐）
> 底层：从多渠道收集低价 API Key，统一路由

---

## 一、核心模型与低价 API 渠道

平台只做两个模型，没有备选。

| 模型 | 用途 | 官方基准价 |

| **GPT-image-2** | 文生图 / 图生图 / 编辑 | $8/1M 输入 token + $30/1M 输出 token（约 $0.03~0.08/张） |
| **Seedance 2** | 文生视频 / 图生视频 | 约 ¥0.6~2.4/秒（字节火山引擎官方价） |

### 1.3 需要"拿到什么"才能接入路由库

每个渠道只要三样东西就能加入你的路由池：

```
渠道 A 的 GPT-image-2：
  1. Base URL：https://api.kie.ai/v1
  2. API Key：sk-xxxxxxxxxxxxxxxx
  3. Model Name/ID：gpt-image-2

渠道 B 的 Seedance 2：
  1. Base URL：https://api.atlascloud.ai/api/v1
  2. API Key：act_xxxxxxxxxxxxxxxx
  3. Model Name/ID：bytedance/seedance-2.0/text-to-video
```

**管理后台设计**：一个表单页面，管理员填入上面三样，点击"验证并添加"，系统自动测试连通性，成功就加入路由池。所有渠道的路由策略在后台配置（如：成本优先 / 轮询 / 成功率优先）。

## 二、系统架构（极简三层）

### 第1层 — 用户端

```
┌──────────────────────────────────────────┐
│              用 户 端                      │
├──────────────────┬───────────────────────┤
│   Web 前端        │   API 接口             │
│   (生图/生视频)    │   (WorkBuddy 用)       │
│                   │                       │
│   用户登录         │   POST /v1/generate   │
│   消耗积分         │   GET /v1/balance     │
│   查看历史         │   需 API Key 鉴权      │
└──────────────────┴───────────────────────┘
```

### 第2层 — 业务服务

| 模块 | 说明 |
|------|------|
| **用户管理** | 普通用户自助注册 + 批量导入学员（Excel 表格） |
| **积分/计费** | 统一积分制，生图扣 X 分，生视频扣 Y 分 |
| **批量导入** | 上传 Excel → 解析姓名+手机号 → 创建账号，手机号+默认密码登录 |
| **积分赠送** | 手动对指定用户/批量对导入用户赠送积分 |
| **API 网关** | 鉴权（API Key）、限流、用量统计 |
| **套餐销售** | 普通用户的订阅/按量套餐 |

### 第3层 — 路由库 + 模型调用

```
                    ┌─────────────────────┐
                    │   路由决策引擎          │
                    │  · 成本优先           │
                    │  · 健康检查自动切换    │
                    │  · 渠道权重分配        │
                    └──────────┬──────────┘
                               │
         ┌─────────────────────┼─────────────────────┐
         ▼                     ▼                     ▼
   ┌─────────────┐      ┌─────────────┐      ┌─────────────┐
   │ Kie.ai      │      │ API易       │      │ laozhang    │
   │ GPT-image-2 │      │ Seedance 2  │      │ GPT-image-2 │
   │ Key Pool    │      │ Key Pool    │      │ Key Pool    │
   └─────────────┘      └─────────────┘      └─────────────┘
         ▼                     ▼                     ▼
   ┌─────────────────────────────────────────────────────────┐
   │              已经验证的 API 路由池                        │
   │  每个条目 = { base_url + api_key + model_name + 权重 }   │
   └─────────────────────────────────────────────────────────┘
```

**路由策略**：

```
用户要生图（GPT-image-2）
  → 检查路由池中所有 GPT-image-2 渠道
  → 按配置的策略排序（默认：成本从低到高）
  → 选第一个健康的渠道发送请求
  → 失败则自动切换到下一个
```

## 三、用户管理方案（极简）

### 3.1 普通用户

自助注册（邮箱/手机号）→ 购买套餐（微信/支付宝）→ 获得积分 → 正常使用

### 3.2 学员（批量导入）

不需要学员管理系统。管理员操作流程：

```
步骤 1：准备 Excel 表格（两列）
  ┌──────┬──────────────┐
  │ 姓名  │ 手机号        │
  ├──────┼──────────────┤
  │ 张三  │ 13800138001  │
  │ 李四  │ 13800138002  │
  │ ...   │ ...          │
  └──────┴──────────────┘

步骤 2：在管理后台上传表格
  → 系统自动创建账号
  → 手机号 = 登录名
  → 默认密码 = 手机号后 6 位（可强制首次登录修改）

步骤 3：手动或批量赠送积分
  → 选中一批用户 → "赠送积分" → 填写数量 + 有效期
  → 或：按"班级"标签批量操作
```

**管理后台的学员功能就两个按钮**：
1. 「批量导入」— 上传 Excel
2. 「赠积分」— 选用户/标签 + 填数量 + 点发送

## 五、WorkBuddy 对接

### REST API（用户获取 API Key 后使用）

```
GET  /v1/user/balance          # 查询积分余额
POST /v1/generate              # 生成（参数见下）
GET  /v1/task/{id}             # 查询异步任务状态
```

**生图请求示例（含上传参考图）**：

```json
POST /v1/generate
{
  "type": "text-to-image",       // text-to-image | image-to-image | edit
  "model": "gpt-image-2",
  "prompt": "一只橘猫在夕阳下打哈欠",
  "image_url": "https://...",   // 图生图/编辑时传参考图 URL
  "size": "1024x1024"
}
```

**生视频请求示例（含上传参考素材）**：

```json
POST /v1/generate
{
  "type": "text-to-video",       // text-to-video | image-to-video
  "model": "seedance-2",
  "prompt": "无人机航拍海岸线日落",
  "image_urls": ["..."],        // 图生视频时传参考图
  "video_urls": ["..."],        // 参考运镜/风格的视频
  "audio_urls": ["..."],        // 参考音频
  "duration": 5,
  "resolution": "720p"
}
```

### WorkBuddy MCP Server（后续开发）

开发一个 MCP 服务器，用户配置 API Key 后在 WorkBuddy 中直接调用：

```json
{
  "mcpServers": {
    "my-ai-platform": {
      "url": "https://api.myplatform.com/mcp",
      "headers": { "X-API-Key": "用户的 API Key" }
    }
  }
}
```

## 八、本地开发说明（不买服务器也能跑）

**完全可以。** 这个系统在本地 100% 可运行，不需要服务器和域名。

本地用 `SQLite` 代替 `PostgreSQL`，开发时只需要一行命令启动。

```bash
# 启动开发服务器
npm run dev
# 浏览器打开
open http://localhost:3000
```

需要买服务器的只有一步：**当你确定要对外开放，让别人也能访问你的平台时**，再买一台云服务器部署即可。开发和调试阶段完全不需要。

## 九、产品经理 Review：你可能还没想到的 15 个功能点

### 必须优先补上的功能

| # | 功能 | 为什么重要 |
|---|------|-----------|
| **1** | **异步任务队列** | Seedance 2 视频生成要 30~120 秒，必须异步。用户提交后给一个任务 ID，轮询或 Webhook 通知结果 |
| **2** | **失败自动退款** | 上游渠道调用失败，积分必须自动退还用户。否则体验极差 |
| **3** | **渠道余额监控** | 上游 API Key 余额不够时自动告警并切换渠道。避免"调用到一半没钱了" |
| **4** | **日志审计** | 记录每次调用的用户、渠道、成功/失败、积分消耗。对账和排错全靠它 |
| **5** | **API 限流** | 防刷：每用户每日/每分钟限制调用次数 |

### 建议加上的功能

| # | 功能 | 说明 |
|---|------|------|
| **6** | **文件存储（OSS）** | 生成后的图片/视频存到阿里云 OSS 或 AWS S3，不存本地 |
| **7** | **免费试用额度** | 新用户注册送 10~30 积分，体验后再付费 |
| **8** | **作品历史库** | 用户所有生成记录自动保存为画廊，可查看/下载/删除 |
| **9** | **Prompt 模板库** | 内置常用模板，降低普通用户的使用门槛 |
| **10** | **API Key 二级体系** | 用户的 API Key 和你采购的渠道 API Key 分开管理 |
| **11** | **落地页** | SEO 友好的营销页面，介绍平台功能和套餐 |
| **12** | **邀请系统** | 学员推荐朋友，双方都获得奖励积分 |
| **13** | **内容安全审核** | 接入云厂商的审核服务，防止违规内容 |
| **14** | **管理端数据看板** | 顶栏放今日调用/收入/新增用户等核心指标 |
| **15** | **多支付渠道** | 微信支付为主，条件允许时加支付宝 |

### 优先级建议

```
第1梯队（不做不行）：
  异步任务队列 → 失败自动退款 → 日志审计 → 渠道余额监控

  作品库 → 免费试用 → API 限流 → OSS 存储

第3梯队（锦上添花）：
  内容审核 → 邀请系统 → Prompt 模板 → 多支付 → 数据看板
```
