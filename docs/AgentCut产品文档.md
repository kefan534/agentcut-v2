# 第一部分：PRD 草稿

## 1. 产品概述与定位

**AgentCut（智能体成片）** 是一个面向多用户的聚合型 AI 创作平台。平台以「智能体（Agent）驱动视频制作」为核心差异化，将原本需要专业剪辑能力的视频生产流程，封装为「一句话需求 → 自动分镜 → 多步编排 → 自动成片」的极简链路；同时横向聚合文本生成、图片生成、音乐作曲、视频生成、3D 等单模型能力，以及去字幕、人声分离、画质增强等轻量工具，形成「创作 — 工具 — 剪辑 — 资产」的完整闭环。

**一句话定位**：让没有剪辑基础的人，用自然语言 + 智能体，几分钟内产出可用的成片视频；让有经验的创作者，用可视化画布精确编排复杂工作流。

**平台形态**：Web 端为主（含响应式与后台管理），多用户账号体系，每个用户拥有独立资产空间与独立积分钱包。模型与工具统一经 API 网关路由，前端页面与具体 API 源解耦。

**核心价值主张**：
- 对创作者：降低专业视频生产门槛，把「创意」和「成片」之间的距离压缩到分钟级。
- 对运营/中小企业：无需招聘剪辑师，批量产出营销短视频。
- 对高校：把 AI 创作作为教学实训，课程即获客，学完即转化。
- 对平台方：通过统一的 API 网关与冷热分层存储，把多模型接入成本、存储成本、运维复杂度降到最低，并保证替换模型供应商时零前端改动。

## 2. 目标用户画像（典型三种 + 扩展两种）

### 2.1 短视频创作者（个人 / MCN 兼职）
- **特征**：抖音/B站/视频号活跃创作者，日更压力大，剪辑基本技能有但深度不够，设备一般。
- **痛点**：选题到成片耗时长；配音/字幕/配乐重复劳动；热点追不上。
- **诉求**：套模板快速出片、自动字幕配音、复用素材。
- **高频场景**：智能剪辑页上传素材 → Agent 自动成片；工具页去字幕/人声分离搬运二创。

### 2.2 高校师生（教师 + 学生）
- **特征**：传媒/设计/计算机相关专业，有实训与作业需求，预算低但对批量账号与教学管理敏感。
- **痛点**：机房环境受限；学生账号管理混乱；需要统一资产与积分池。
- **诉求**：班级资产池、批量开户、课程积分包。
- **高频场景**：高校合作模块班级管理；单模型页做文生图/文生视频作业；画布页教工作流编排。

### 2.3 中小企业运营人员
- **特征**：电商/本地生活/教培行业，1-3 人市场团队，无专职剪辑。
- **痛点**：营销视频需求高频但预算紧；外包贵且慢。
- **诉求**：用产品图/口播稿一键生成带货短视频；成本可控。
- **高频场景**：单模型页图生视频；智能剪辑页批量生成；积分按次消耗、可预测成本。

### 2.4 扩展 — 专业创作者 / 设计师（进阶用户）
- 需要精确控制节点参数、复用工程、跨页面联动，重度使用画布 + Agent 页与资产回流。

### 2.5 扩展 — 平台管理员 / 运维
- 关注 API 源健康、存储费用、CDN 流量、备份状态、用户与订单，使用后台管理。

## 3. 核心功能描述（每页 200–300 字）

### 3.1 单模型页
单模型页是平台能力的「原子入口」，让用户单独调用某一类 AI 模型，不引入工作流复杂度。当前覆盖四大模态：文本生成（文案/脚本/分镜稿）、图片生成（文生图/图生图/参考生图）、音乐作曲（情绪/风格/时长可控）、视频生成（文生视频/图生视频/参考生视频）。每个模型展示为独立卡片，用户选择模型变量（如 `IMAGE_MODEL`）、填写 prompt、上传可选参考图/视频、配置参数（尺寸、时长、数量等），点击生成后实时展示进度与结果。所有产物自动写入用户资产空间，并支持一键「发送到画布」或「发送到智能剪辑页」继续加工。该页强调「快」——无编排负担，适合明确知道自己要什么的用户。

### 3.2 画布 + Agent 页
画布 + Agent 页是可视化工作流编排台，用户在一个无限画布上拖拽节点（模型调用、工具处理、条件分支、变量传递等）、连线定义数据流向、配置每个节点的参数，手动点击运行得到结果；也可切换到「Agent 驱动模式」，用自然语言描述目标，由 Agent 自动在画布上生成节点、连线并逐步执行，用户可随时介入修改。画布工程文件可保存为「工程资产」反复读取。它的核心是「可控的复杂工作流」——适合多步骤、需精确编排、可复用的生产任务（如固定风格的周更视频模板）。注意：本页的 Agent 是「画布的驾驶者」，产物落在画布节点与工程文件中。

### 3.3 Agent 全功能页（与画布页的区别，重点说明）
Agent 全功能页是**纯对话式、与画布解耦**的独立智能体交互界面。用户用对话创建复杂任务：Agent 先做意图分析 → 必要时澄清提问 → 产出可编辑的分镜/步骤清单 → 用户确认 → 调用网关模型与工具多步执行 → 实时推送进度 → 输出成片与中间资产。它与画布页的关键区别有四点：（1）**交互形态**：本页是聊天/任务流，画布页是节点图；（2）**状态载体**：本页状态是会话与任务链（存于后端 thread），画布页是工程文件；（3）**协作关系**：本页不直接操作画布节点，结果可导出或「发送到画布」二次精修，二者单向/双向联动但不耦合；（4）**适用心智**：本页适合「说清楚要什么就行」，画布页适合「我亲自搭流水线」。历史会话可管理、可恢复、可导出。

### 3.4 工具集合页
工具集合页是轻量级 AI 工具箱，把高频实用功能做成即用即走的卡片，无需编排。当前规划至少 15 个工具：去字幕、人声分离、视频超分、画质增强、TTS 文字转语音、智能抠图、OCR 文字识别、PDF 处理（合并/拆分/提取）、视频转 GIF、音频降噪、语音克隆、字幕翻译、视频压缩、图片放大、背景替换。每个工具标注接入方式（ffmpeg / 自部署模型 / 外部 API），用户上传素材、点一下、下载结果，处理结果可作为资产回传到画布页当节点输入。它解决的是「用户手头有一段素材、只想做个单一处理」的长尾需求，是留存与引流的重要抓手。

### 3.5 智能剪辑页
智能剪辑页面向「我有一段/一批素材，帮我剪成片」的用户。用户上传视频/图片/音频素材（自动进入资产空间），用自然语言或表单描述需求（风格、时长、旁白文案、是否加字幕/BGM/转场），Agent 自动完成：素材筛选与排序、配音（TTS）、配乐、字幕生成、转场与节奏匹配，输出成品视频并支持在线预览与导出。中间产物（时间轴草稿、各片段）可回流到画布页做二次编辑。它是平台离「终局体验」最近的一页，目标是让非剪辑用户零学习成本拿到成片。

### 3.6 资产 / 个人中心页（补充）
用户的私有资产空间与积分钱包入口，集中管理上传素材、AI 产物、中间文件，查看存储用量与层级分布，管理积分充值/消耗/签到，是贯穿所有页面的「个人账户中枢」。

```

        │     选模型(IMAGE_MODEL) → 文生图 → 发送到画布/剪辑 → 成片

        │     拖节点/连线 → 运行 / Agent 驱动 → 工程保存 → 导出
```

## 7. 技术架构简述

### 7.1 API 网关路由层（四级分类 + 自动切换）
所有页面调用的模型/工具均通过统一 API 网关，前端只认「变量名」不认「具体地址」。

- **四级分类**：
  1. 模态分类：文本 / 图片 / 音频 / 视频 / 3D；
  2. 厂商分类：OpenAI、Anthropic、腾讯混元、火山引擎、Stability AI 等；
  3. 模型版本：GPT-4o、Claude 3.5 Sonnet、混元 Turbo 等；
  4. API 源：官方直连 / 第三方代理 / 自部署镜像（同版本可有多源，按优先级排序）。
- **变量名映射**：每个模型/工具对应固定变量（如 `TEXT_MODEL`、`IMAGE_MODEL`、`VIDEO_MODEL`、`AUDIO_STEM_MODEL`、`TTS_MODEL`、`UPSCALE_MODEL`），页面硬编码变量名，网关解析到具体源。
- **自动切换**：主源超时/报错时，按优先级自动切备用源；可配置超时阈值、重试次数。
- **条件优先**：按用户等级（付费优先高速源）、时间段（高峰用低成本源）、成本策略（默认走最廉价可用源）选择最优源。
- **隔离机制**：修改 API 源仅在后端配置变更，前端与页面代码零改动。

### 7.2 多用户资产存储系统（三层冷热 + CDN + 异地备份）
- **上传**：业务服务器签名 → 直传云对象存储（COS/OSS/七牛/R2）标准层，支持断点续传与进度。
- **三层生命周期**（自动沉降，用户无感知）：
  - 0–30 天：热访问 → 标准存储层；
  - 31–120 天（90 天无访问）：→ 低频层（约 ¥0.08/GB/月）；
  - 121 天+（180 天+无访问）：→ 归档层（约 ¥0.033/GB/月）。
- **CDN 加速**：统一 CDN 域名回源，回源走云厂商同区域内网免流量费；支持 Range 请求（视频拖拽播放）。
- **置顶/收藏**：标记资产永久留标准层，不降级。
- **异地备份（3-2-1）**：NAS/自建 MinIO 经 rclone 每周增量同步（内网/VPN，不走公网），仅备份不对外服务；满足 3 份副本、2 种介质、1 份异地。
- **用户感知**：资产读写体验一致，仅归档层回源可能略有延迟（CDN 缓存缓解）；提供用量统计与容量提醒。

## 8. 页面联动关系图（数据流转，文字描述）

- **单模型页 → 画布页 / 智能剪辑页**：文生图/文生视频等产物一键发送，自动写入接收方用户资产空间，作为画布节点输入或剪辑素材。
- **工具集合页 → 画布页**：去字幕/人声分离等结果回传画布，作为节点输入继续编排。
- **Agent 全功能页 → 工具集合页**：Agent 在执行任务链时，可把轻量工具当子步骤调用（如先 OCR 再配音）。
- **智能剪辑页 → 画布页**：剪辑中间产物（时间轴草稿、片段）回流画布做二次精修。
- **画布页 → 智能剪辑页 / 单模型页**：画布导出产物可发送到剪辑页或作为单模型输入。
- **全局共享**：所有页面共享同一积分系统与同一用户资产空间；跨页传递的资产自动写入接收方资产空间，无需重复上传。
- **资产页为枢纽**：所有产出最终沉淀到资产页，被任意页面读取。

## 9. 存储架构说明

- **分层规则**：标准层（0–30 天热访问）→ 低频层（31–120 天且无访问 90 天）→ 归档层（121 天+且无访问 180 天）。生命周期由对象存储规则自动执行，无需人工。
- **CDN 内网回源免流**：CDN 回源域名指向同区域对象存储内网地址，不产生公网流量费；全站通过 CDN URL 取资产，支持 Range 实现视频拖拽。
- **rclone 周级增量备份**：自建 NAS/MinIO 通过 rclone 每周增量同步云存储，链路走内网/VPN，满足 3-2-1（3 份副本、2 种介质、1 份异地），备份节点不承接用户访问。
- **用户无感知**：资产 URL 不变，读取速度不受层级影响（归档层回源延迟由 CDN 缓存兜底）；置顶资产永留标准层。
- **管理可见**：个人仪表盘展示已用容量、各类型/各层级占比；管理员面板展示全站用量、层级费用、CDN 流量、迁移日志、备份状态。

## 11. 工作流页面与积分分成机制（新增）

### 11.1 工作流页面：三个 Tab 与收藏

工作流页面是平台「创作沉淀与复用」的核心入口，承载社区化分享与克隆消费。页面自上而下分为：

- **顶部全局筛选与搜索**：按模态（文本/图/音/视频/3D）、标签、热度、最新排序；支持关键词搜索工作流标题/作者。
- **Tab 一 · 一键同款（单模型页维度）**：以「单模型成品模板」形式呈现，用户点击即按该模型的固定变量（如 `IMAGE_MODEL`、`VIDEO_MODEL`）与预设 prompt 一键复刻出同款成片/图像，是零编排门槛的克隆入口。
- **Tab 二 · 画布工作流**：以可视化画布工程为单位的分享流，用户可整体克隆他人画布到自己的空间后自由改造（改节点、改参数、改连线）。
- **Tab 三 · Agent 工作流**：以「Skill（技能）」为单位的分享流，克隆他人的 Agent 技能到自己的 Agent 全功能页，直接复用其意图分析 → 分镜 → 执行的编排逻辑。
- **收藏功能**：每个工作流卡片/详情页均支持「收藏」，收藏列表在个人中心可统一管理；收藏不影响积分，仅用于个人留存与快速访问。

> 三类工作流共用同一套克隆经济模型（见 11.3），区别仅在克隆落点（单模型同款 / 画布空间 / Agent 技能）。
> 注：本 PRD 第 3 章已分别描述单模型页、画布+Agent 页、Agent 全功能页的能力；本章的「工作流页面」是这些能力的**可分享化与社区化封装**，聚焦「他人创作 → 我克隆 → 双方分成」的闭环。

#### 11.1.1 工作流发布、审核与推荐（供给侧链路）

工作流市场的「内容从哪来」是分成机制成立的前提。本平台采用**轻审核、强推荐**的供给侧链路，完整业务流如下（与用户确认的预期一致）：

> **发布者把满意的成品「分享到工作流市场」→ 管理员在后台审核队列点击「通过 / 推荐」→ 该工作流出现在对应 Tab 的展示页 → 克隆者克隆时按 `workflow_clone_cost` 扣积分 → 平台留存 50%、分享者获得 50%。**

- **状态机**：`draft`（本地草稿，仅作者可见）→ `pending_review`（提交市场，进入审核队列）→ `published`（已上架，公域展示）→ `taken_down`（下架，违规/侵权/作者撤回）。
- **三个 Tab 各自的发布来源**：
  - 一键同款：来自单模型页某次满意成品 → 「另存为同款模板」（含固定模型变量 `IMAGE_MODEL`/`VIDEO_MODEL` + 预设 prompt）。
  - 画布工作流：画布工程「发布到市场」（含节点 JSON + 连线 + 资产引用，资产以引用计数去重，不整文件拷贝）。
  - Agent 工作流：Agent 全功能页某 Skill「发布到市场」（含意图分析 → 分镜 → 执行的编排逻辑）。
- **管理员后台操作**：审核队列（通过 / 驳回并附理由）、推荐开关（`is_recommended` + `priority` 控制展示页排序与 Banner 位）、下架（`takedown`）。
- **可见性规则**：未审核、被驳回、已下架的内容**不进入公域展示页**，仅作者本人可见；只有 `published` 且被推荐的工作流才出现在展示页与推荐位。

#### 11.1.2 克隆通知（分享者收益感知）

分成的激励效果取决于分享者**能否感知到收益**。本平台在克隆成功且产生分成流水（非自克隆、首次）后，向分享者推送一条站内通知：

- **文案示例**：「您的「国风卡点混剪模板」被用户 @剪辑小能手 克隆，获得 5 积分分成。」
- **入口**：全局顶部铃铛（`unread-count` 轮询/推送）、个人中心通知列表（历史可查、可标记已读）。
- **时序约束**：通知在积分三流水事务**提交之后**异步写入，确保通知发送失败**不会回滚**已正确的分成；通知属于感知层，不参与账本一致性。
- **价值**：让分享者「看得见」每一次被克隆带来的收益，是持续创作、沉淀优质 UGC 的核心激励。

#### 11.1.3 发现与分发：搜索 / 排序 / 推荐位

展示页除三 Tab 与收藏外，需具备基础分发能力，避免优质内容沉底：

- **搜索**：顶部支持关键词搜索（标题 / 作者昵称 / 标签），后端全文检索。
- **筛选**：按模态（文本 / 图 / 音 / 视频 / 3D）、标签维度过滤。
- **排序**：
  - **热度（默认）**：热度分 `= (克隆数×3 + 收藏数×1 + 浏览数×0.1) / (发布时长小时 + 2)^1.2`，带时间衰减（Hacker News 风格），保证新内容有曝光机会。
  - **最新**：按发布时序倒序。
  - **推荐**：管理员标记为推荐的工作流优先（置顶 + 按 `priority` 排序）。
- **推荐位**：管理员在审核通过后标记「推荐」，展示页以 Banner / 置顶卡呈现；这是冷启动期引导优质内容分发、制造标杆案例的主要运营手段。

### 11.2 核心理念

每一次「克隆」行为都是一次价值交换：

- **克隆者**获得他人创作的工作流 / 技能，省去自己从零搭建的时间与算力；
- **分享者**贡献了自己的创作成果，应获得收益激励以持续创作；
- **平台**作为撮合方与基础设施提供方（存储、网关、算力路由、CDN），抽取合理比例维持运营。

据此建立「克隆即付费、分享即获利」的正向循环，驱动 UGC 内容沉淀与平台活跃。

**积分流通闭环（价值闭环澄清）**：平台内积分是**统一流通货币**——无论是用户充值所得、签到/赠送所得，还是分享工作流被克隆获得的**分成积分**，都进入**同一个用户积分钱包**，可无差别地用于调用模型、使用工具、克隆他人工作流。因此「分享者获得的 X×50% 积分」并非「没处花的虚高数字」，而是可以直接抵扣其下一次成片/生成消耗的算力成本。这条闭环是克隆分成激励能长期成立的前提：**创作 → 被克隆 → 获积分 → 再创作**，货币始终在平台内循环，无需提现即具备真实价值。

### 11.3 分成公式（后台可配置）

设单次克隆由管理员在后台配置的消耗积分为 `X`（`workflow_clone_cost`，单位：积分，整数）：

```
克隆者消耗积分        = X
分享者获得积分        = X × 50%
平台留存积分（收入）  = X × 50%
```

- `X` 初始建议在 Beta 阶段测流通量后确定，正式上线前由运营填写（见 11.4）。
- 分成比例（当前固定 50%/50%）作为可配置项预留，未来可分层（如头部创作者 60%/40%）。
- **奇数分配补齐**：当 `X` 为奇数时，分享者获得 `floor(X/2)`，平台获得 `X - floor(X/2)`（余数自动归入平台公共积分池），保证三条流水金额之和恒等于 `X`、无积分凭空消失或凭空产生。

### 11.4 后台配置项

路径：**后台管理系统 → 积分配置 → 新增字段**

| 字段名 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `workflow_clone_cost` | 整数 | 暂空（Beta 期间填 0） | 每次克隆工作流时克隆者消耗的积分数；分享者获得此值的 50%，平台留存 50% |

- Beta 期间填 0：克隆免费（鼓励冷启动内容与测试），正式上线前根据「积分经济仪表盘」的全站流通量测算后填写（见 11.9）。
- 该配置为**全局单一值**，三个 Tab（一键同款 / 画布工作流 / Agent 工作流）共用，**不分设**。

### 11.5 三个 Tab 的统一与差异

| Tab | 克隆触发点 | 扣积分值 | 落点 |
|---|---|---|---|
| 一键同款（单模型页） | 点击「克隆同款」生成时 | `workflow_clone_cost` | 生成同款产物到克隆者资产空间 |
| 画布工作流 | 点击「克隆到我的画布」时 | `workflow_clone_cost` | 画布工程复制到克隆者空间 |
| Agent 工作流 | 点击「克隆 Skill 到 Agent」时 | `workflow_clone_cost` | Skill 复制到克隆者 Agent 页 |

三者**共用同一个后台配置值 `workflow_clone_cost`**，不分设；扣减时机统一为「克隆动作发起、克隆成功落库时」。

### 11.6 积分流水记录

每次克隆行为（且首次、跨用户、非自克隆，见 11.7）成功落库后，**原子地产生三条积分流水记录**（同一 `share_record_id` 关联）：

| # | 账户 | 方向 | 金额 | 备注（remark） |
|---|---|---|---|---|
| 1 | 克隆者 | 支出 | X | 克隆[工作流标题]（如：克隆「国风卡点混剪模板」） |
| 2 | 分享者 | 收入 | X×50% | 您的[工作流标题]被克隆（如：您的「国风卡点混剪模板」被克隆） |
| 3 | 平台公共积分池 | 收入 | X×50% | 克隆撮合服务费（workflow_clone_cost） |

- 三条记录在同一数据库事务内写入，保证「不重不漏」；任一条失败则整体回滚（防资损）。
- 平台流水归入**平台公共积分池**（非某具体用户钱包），用于冲抵算力成本与运营。

### 11.7 防刷机制

- **首次扣费**：同一用户克隆同一工作流仅**首次**扣积分；重复克隆同一工作流免费（克隆到自己空间后可任意改造，不再计费）。
  - 实现：以 `(cloner_user_id, source_workflow_id)` 唯一约束记录已克隆关系；已存在则不发扣费事务。
- **禁止自克隆获利**：分享者克隆自己的作品**不分成**（自己克隆自己，三流水中第 2、3 条不生成，第 1 条也不扣费）。
  - 实现：克隆发起时校验 `cloner_user_id == author_user_id`，命中则跳过计费直接复制。
- **每日克隆次数上限**：可配置防刷阈值（后台 `daily_clone_limit`，默认如 50 次/日），超限后当日停止克隆并提示。
- 后续可叠加：设备指纹 / 同 IP 多账号风控（v2.0）。

### 11.8 积分流水数据模型（新增字段说明）

在既有积分流水表（credit_ledger）基础上，针对克隆类流水新增/补充以下字段：

| 字段 | 类型 | 含义 | 说明 |
|---|---|---|---|
| `share_record_id` | bigint / uuid | 分享事件流水组 ID | 一次克隆产生的三条流水共用同一 `share_record_id`，用于关联、对账与退款回溯 |
| `clone_type` | enum | 克隆类型 | `one_click`（一键同款）/ `canvas`（画布工作流）/ `agent`（Agent 工作流） |
| `split_ratio` | int | 分成比例（百分比） | 如 `50` 表示分享者与平台各 50%；预留分层（头部 60/40） |
| `ref_workflow_id` | bigint | 被克隆工作流 ID | 关联源工作流（含 Tab 与标题快照） |
| `counterparty_user_id` | bigint / null | 交易对手用户 ID | 克隆者流水的对手为分享者；分享者流水的对手为克隆者；平台流水为 null |
| `scope` | enum | 流水业务域 | `clone` / `model_call` / `tool_use` / `sign` / `recharge` / `gift`（区分克隆与其它消费） |
| `split_share` | int | 分享者分成额 | 冗余存储，便于统计，= 交易额 × split_ratio% |
| `split_platform` | int | 平台分成额 | 冗余存储，= 交易额 × (100 - split_ratio)% |
| `user_id` / `tx_type` / `amount` / `balance_after` / `remark` / `created_at` / `ref_id` | — | 既有字段保持不变 | 克隆流水复用现有字段，`scope='clone'` 区分 |

### 11.9 后台「积分经济仪表盘」功能说明

路径：**后台管理系统 → 积分经济仪表盘**（新增）

目标：为 `workflow_clone_cost` 的取值提供数据依据，并监控全站积分健康度。

| 指标卡 | 计算口径 | 用途 |
|---|---|---|
| 全站积分发行总量 | 签到 + 赠送 + 充值 之和（累计） | 流动性供给 |
| 全站积分消耗总量 | 模型调用 + 工具使用 + 克隆消耗 之和（累计） | 流动性回收 |
| 日均积分流通量 | 近 7/30 日 (发行+消耗)/天数 | 判断活跃与通胀压力 |
| `workflow_clone_cost` 建议值 | 根据流通量/通胀通缩趋势自动推算参考值（消耗增速 > 发行增速 → 建议上调） | 辅助运营定价 |
| 手动调整日志 | 谁（admin_id）在何时（ts）把值从 A 改成 B，含原因备注 | 审计与追责 |

- 仪表盘提供趋势图（发行 vs 消耗曲线）、Top 分享者榜、Top 被克隆工作流榜，辅助运营识别高价值内容。
- 建议值仅作参考，最终取值由运营在「积分配置」手动确认写入。

## 12. 商业模式（新增章节）

AgentCut 的收入与成本结构如下：

**收入来源**
1. **积分充值（主营收入）**：用户购买算力积分，覆盖模型调用、工具使用、克隆消耗。**积分是平台内统一流通货币**——充值所得与分享所得（克隆分成）积分进入同一用户钱包，无差别地用于模型调用、工具使用、克隆消费，形成「创作→被克隆→获积分→再创作」的内循环（详见 11.2 流通闭环）。
2. **工作流分成（平台留存）**：克隆行为中平台留存 `X × 50%` 积分（见 11.3），本质为「撮合服务费」——这是平台**轻资产、可随 UGC 规模放大**的收入来源之一，且不直接增加算力边际成本。
3. **高校/企业批量套餐**：班级/企业积分池与账户包（见第十二章 高校合作模块）。
4. **（未来）会员订阅 / 高级模型优先源**：v2.0 条件优先路由的商业化包装。

**成本结构**
- 模型/工具 API 调用成本（随用量线性）；
- 存储（三层冷热）+ CDN 流量；
- 异地备份链路（rclone 内网）；
- 平台运营与研发。

**单位经济模型**：单次克隆平台收入 = `X × 50%` 积分对应的现金价值；当 UGC 工作流规模增长，分成收入呈近零边际成本放大，是平台长期盈利的重要杠杆。Beta 期 `workflow_clone_cost = 0`，该收入项为 0，待流通量测算后开启。

## 附录：与现有代码库（AgentCut）待对齐的关键风险（来自 QA 测试）
本 PRD 的「核心基础设施」章节（API 网关、存储、积分、权限）对应到当前代码仓库，已有 QA 测试报告标记以下必须与本 PRD 同步修复的 P0：
1. Agent 全功能页主路径成片**未扣积分**（功能清单已列「Agent 成片计入积分扣减 P0」）。
2. Agent 线程接口**缺少归属校验（IDOR）**（功能清单已列「线程归属校验 P0」）。
3. 幽灵线程导致 Agent 页**白屏**，且缺全局 Error Boundary（功能清单已列「Error Boundary P0」「线程状态持久化 P0」）。
4. 注册**零校验**、鉴权失败返 500（功能清单已列「注册校验 P0」「401 全局拦截 P0」）。
5. 图像尺寸/质量/负面提示词**不生效**（功能清单已列「参数真实透传 P0」「负面词生效 P1」）。
6. 历史/资产**无真分页**（功能清单已列资产列表页 P1，需补服务端分页）。
7. 画布复制节点**丢连线**、旧闭包 state（功能清单已列对应 P0/P1）。

> 命名说明：项目正确名称为 **AgentCut**（Agent + Cut，智能体成片）。早期版本曾误用其他拼写，现已统一修正为 AgentCut。
